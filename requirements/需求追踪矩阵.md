## 1. 矩阵说明

本矩阵建立"需求编号 → 用例 → 验证方式"的完整映射，确保每一条需求均可追溯到对应的用例与验证手段，支撑后续设计、开发与测试任务拆分。

- **需求编号**：功能需求 `FR-模块号-序号`，非功能需求 `NFR-序号`。
- **来源角色**：需求提出/主要使用角色（管理员 / 教师 / 学生 / 全角色 / 系统）。
- **关联用例**：对应 `用例图.puml` 中的用例（以用例名称标识）。
- **验证方式**：功能测试 / 接口测试 / 性能测试 / 安全测试 / 兼容性测试 / 代码审查 / 人工验证。
- **状态**：待开发 / 开发中 / 已完成 / 已验证。本期统一为"待开发"。
