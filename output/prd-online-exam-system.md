# PRD: 在线考试系统

## 1. 需求背景

随着教育信息化的发展，传统的纸质考试方式已经无法满足现代教学的需求。在线考试系统能够解决传统考试中存在的效率低下、阅卷周期长、成绩统计繁琐等问题。特别是在小规模教育机构和培训场景中，需要一个轻量级、易部署的在线考试解决方案。

本系统旨在为教师和学生提供一个完整的在线考试管理平台，实现从题库建设、试卷生成、在线考试、智能阅卷到成绩统计的全流程数字化管理。

## 2. 目标与价值

**目标：**
- 支持5种题型（单选、多选、判断、填空、简答）的题库管理
- 实现限时考试功能，倒计时自动提交试卷
- 支持自动评分（客观题）和人工阅卷（主观题）
- 提供成绩统计和分析功能
- 支持管理员、教师、学生三种角色的权限管理
- 满足100人以下小规模并发考试需求

**价值：**
- 提高考试组织效率，减少人工工作量
- 实现考试流程标准化，降低出错率
- 提供数据支持，便于教学质量分析
- 为学生提供灵活的考试时间和地点

## 3. 术语/角色定义

**角色定义：**
- **管理员**：系统最高权限，管理用户账号、系统设置、权限分配
- **教师**：负责题库管理、试卷组卷、阅卷、成绩查看
- **学生**：参加考试、查看成绩、查看错题

**术语说明：**
- **题库**：存储试题的数据库，按课程和章节分类
- **试卷**：从题库中选取试题组成的考试内容
- **考试**：设置考试时间和规则的考试活动
- **客观题**：单选题、多选题、判断题、填空题，系统自动评分
- **主观题**：简答题，需要教师人工阅卷

## 4. 适用范围

**功能范围：**
- 题库管理：试题的增删改查、分类管理
- 试卷管理：手动组卷、自动组卷、试卷发布
- 考试管理：考试创建、时间设置、考生管理
- 在线考试：限时答题、倒计时、自动提交
- 阅卷管理：客观题自动评分、主观题人工阅卷
- 成绩统计：成绩查询、数据分析、导出

**适用场景：**
- 高校课程考试
- 培训机构测试
- 企业招聘笔试
- 在线认证考试

**不适用范围：**
- 视频监控防作弊功能
- 人脸识别身份验证
- 大规模高并发场景（>100人）

## 5. 非目标/范围外

本系统**不包含**以下功能：
- 在线监考和防作弊功能
- 人脸识别和身份验证
- 直播教学功能
- 大规模并发支持（>100人）
- 移动端APP开发（仅Web响应式）
- 多语言支持

## 6. 功能需求

### 6.1 用户管理模块

- **FR-1**：管理员可以创建、编辑、删除用户账号
- **FR-2**：系统支持三种角色：管理员、教师、学生
- **FR-3**：教师和学生可以修改个人信息和密码
- **FR-4**：学生通过学号/账号登录，教师通过工号登录

### 6.2 题库管理模块

- **FR-5**：教师可以添加5种题型（单选、多选、判断、填空、简答）
- **FR-6**：试题支持按课程、章节分类
- **FR-7**：支持批量导入试题（Excel/CSV格式）
- **FR-8**：支持试题检索、筛选、编辑和删除
- **FR-9**：题库支持试题难易度标记（简单、中等、困难）

### 6.3 试卷管理模块

- **FR-10**：教师可以从题库手动选择试题组卷
- **FR-11**：支持按题型、难易度自动组卷
- **FR-12**：试卷可以设置总分、及格分、考试时长
- **FR-13**：试卷支持预览功能
- **FR-14**：试卷发布后可以被指定学生参加考试

### 6.4 考试管理模块

- **FR-15**：教师可以创建考试，设置考试名称、时间、时长、参与学生
- **FR-16**：考试支持限时模式，倒计时结束后自动提交
- **FR-17**：学生可以在考试时间内进入考试
- **FR-18**：考试过程中显示倒计时提醒
- **FR-19**：支持考试中断续答（断网恢复后继续答题）

### 6.5 在线答题模块

- **FR-20**：学生登录后可以看到已发布的考试
- **FR-21**：答题界面显示题目导航（已完成、当前、未完成）
- **FR-22**：客观题支持单选、多选、判断、填空答题
- **FR-23**：主观题（简答）支持文本编辑
- **FR-24**：考试结束或倒计时结束自动提交试卷
- **FR-25**：提交后客观题自动评分

### 6.6 阅卷管理模块

- **FR-26**：系统自动批改客观题（单选、多选、判断、填空）
- **FR-27**：教师可以人工批阅主观题（简答题）
- **FR-28**：阅卷时显示学生答案和标准答案
- **FR-29**：支持批量阅卷和单题阅卷模式
- **FR-30**：阅卷完成后自动计算总分

### 6.7 成绩统计模块

- **FR-31**：学生可以查看自己的考试成绩和错题
- **FR-32**：教师可以查看所有学生的考试成绩
- **FR-33**：支持按班级、课程筛选成绩
- **FR-34**：提供成绩分布统计图表（直方图、饼图）
- **FR-35**：支持成绩导出为Excel格式

## 7. 关键流程/交互说明

### 7.1 题库管理流程

```
教师登录 → 进入题库管理 → 选择课程 → 添加/编辑/删除试题 → 保存到题库
```

**详细步骤：**
1. 教师选择课程分类
2. 选择题型（单选/多选/判断/填空/简答）
3. 填写题干、选项（如有）、标准答案、解析
4. 设置难易度（简单/中等/困难）
5. 保存试题到题库

### 7.2 组卷流程

```
教师进入试卷管理 → 创建试卷 → 手动/自动选题 → 设置分值 → 预览试卷 → 发布试卷
```

**手动组卷：**
1. 从题库按分类筛选试题
2. 手动选择需要的试题
3. 设置每道题的分值
4. 调整题目顺序
5. 预览并发布

**自动组卷：**
1. 设置题型、难易度、数量要求
2. 系统从题库随机抽取符合条件的试题
3. 自动设置默认分值
4. 预览并发布

### 7.3 考试流程

```
学生登录 → 查看考试列表 → 进入考试 → 答题 → 提交 → 查看成绩
```

**详细步骤：**
1. 学生登录系统
2. 在考试列表中找到待参加的考试
3. 进入考试页面，阅读考试说明
4. 开始答题，系统开始倒计时
5. 逐题作答，可标记不确定的题目
6. 完成所有题目后提交试卷
7. 系统自动批改客观题
8. 查看成绩（客观题分数）

### 7.4 阅卷流程

```
教师进入阅卷 → 选择考试 → 批阅主观题 → 提交分数 → 系统计算总分
```

**详细步骤：**
1. 教师选择需要阅卷的考试
2. 系统展示待阅卷的学生列表
3. 逐个批阅主观题（简答题）
4. 输入分数和评语
5. 完成所有主观题阅卷
6. 系统自动计算总分并更新成绩

## 8. 风险与依赖

### 8.1 风险评估

**高风险：**
- 考试过程中系统崩溃导致学生答题数据丢失
  - **应对策略**：实现自动保存功能，每30秒保存一次答题进度
- 网络中断影响考试进行
  - **应对策略**：支持断网续答，本地缓存答题数据

**中风险：**
- 并发量过大导致系统响应缓慢
  - **应对策略**：优化数据库查询，使用Redis缓存
- 客观题评分规则不准确
  - **应对策略**：严格测试评分逻辑，支持多种答案格式

**低风险：**
- 用户操作不熟悉导致误操作
  - **应对策略**：提供操作指引和帮助文档

### 8.2 依赖项

**技术依赖：**
- 前端框架：React 18+
- 后端框架：Node.js + Express
- 数据库：MySQL 8.0+
- 缓存：Redis（可选，用于会话管理）
- 图表库：ECharts（成绩统计）

**外部依赖：**
- 无外部系统依赖
- 所有功能均为自研

## 10. 开放问题

1. **考试次数限制**：是否允许学生多次参加同一考试？
   - 建议：默认允许1次，教师可设置允许重考次数

2. **题目随机顺序**：是否需要打乱题目顺序防止作弊？
   - 建议：提供选项，教师可选择是否打乱题目顺序

3. **成绩公布方式**：考试结束后是否立即公布成绩？
   - 建议：客观题成绩立即公布，主观题阅卷后公布

4. **错题本功能**：是否需要为学生提供错题本功能？
   - 建议：作为V2.0功能，当前版本暂不实现

5. **考试通知**：是否需要添加考试提醒和通知功能？
   - 建议：作为V2.0功能，当前版本通过系统内通知实现
