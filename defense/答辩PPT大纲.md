## 第 2 页 · 研究背景与意义

**标题**：研究背景与意义

**要点内容**：
- **传统纸质考试的局限性**：命题→印卷→分发→收卷→阅卷→登分→统计全流程耗费人力；阅卷周期长（天级）；成绩统计易出错；防作弊手段有限
- **教育信息化趋势**：教育信息化 2.0 行动计划 + "互联网+教育"普及，在线考试系统应运而生
- **在线考试的五大优势**：
  1. 大幅缩短考试组织周期，教师在线命题组卷，学生随时随地参考
  2. 客观题自动阅卷，阅卷时间从天级压缩至秒级
  3. 电子化答卷便于成绩统计分析与数据挖掘
  4. 切屏检测、禁止复制粘贴等前端防作弊手段增强公平性
  5. 题库资源积累与复用，降低命题成本
- **本系统定位**：面向小规模（≤100 人并发）教育与培训场景，轻量级、易部署、流程完整、可二次开发

**配图建议**：左侧"传统考试流程"vs"在线考试流程"对比图（流程箭头），右侧痛点→优势转化箭头

## 第 3 页 · 国内外研究现状

**标题**：国内外研究现状与对比分析

**要点内容**：
- **国外现状**：
  - Moodle Quiz：开源免费，多题型与随机组卷，但中文本地化差、组卷统计偏弱、运维门槛高
  - ExamSoft / ProctorU：集成在线监考与人脸识别，适用高利害考试，部署成本与门槛高
  - Canvas / Blackboard：LMS 内置考试模块，独立部署能力有限
- **国内现状**：
  - 超星学习通：功能全面、大规模并发、移动端覆盖好，但部署重、定制化差、数据归属不清
  - 智考网 / 考试酷：题库丰富、组卷灵活，但广告多、二次开发困难
  - 校内自研系统：贴合本校流程，但多为单点功能、缺乏全流程闭环、可维护性差
- **两极分化问题**：商业平台功能全但重；自研系统轻但功能单薄
- **本系统定位**：在功能完整性与轻量易部署之间取得平衡，全中文界面 + Ant Design 开箱即用

## 第 5 页 · 技术选型

**标题**：技术选型与选型理由

**要点内容**：
- **前端技术栈**：
  - React 18：组件化 + 虚拟 DOM + Hooks，并发渲染特性，适合中后台 + 答题场景
  - React Router 6：嵌套路由 + 懒加载 + 路由守卫
  - Zustand 4：轻量无样板代码，替代 Redux 降低心智负担，支持非组件上下文访问状态
  - Ant Design 5：企业级组件库，Table/Form/Upload/Modal 开箱即用
  - Vite 5：ESM 极速冷启动 + HMR，构建产物体积小
  - Axios：拦截器统一处理 JWT 注入与错误码
- **后端技术栈**：
  - Node.js 18 LTS：非阻塞 I/O 契合并发答题与暂存场景，前后端同语言降低全栈成本
  - Express 4：轻量灵活，中间件生态丰富
  - Sequelize 6 ORM：参数化查询防 SQL 注入，模型关联 + 事务 + 软删除
- **数据与安全**：
  - MySQL 8.0：utf8mb4 支持中文，InnoDB 事务与行级锁
  - JWT（jsonwebtoken）：无状态认证，有效期 2h
  - bcrypt：加盐哈希抗彩虹表

- **代码规模**：后端 46 个源文件，前端 41 个源文件

## 第 7 页 · 数据库设计

**标题**：数据库设计

**要点内容**：
- **10 个核心实体**：User、Class、Question、Paper、PaperQuestion、Exam、ExamClass、ExamRecord、Answer、GradeTask（+ SysConfig 共 12 张表）
- **关键关系**（16 个一对多 + 2 个多对多）：
  - 班级 1—N 学生
  - 教师 1—N 题目/试卷/考试（creator_id）
  - 试卷 N—M 题目（通过 paper_questions，含分值与排序）
  - 考试 N—M 班级（通过 exam_classes，指定参考范围）
  - 考试 1—N 考试记录 1—N 答题记录
  - 考试 1—N 阅卷任务
- **索引策略**：
  - users.username、classes.name 唯一索引
  - questions(type, difficulty, knowledge_point) 联合索引支撑题库筛选
  - exam_records(exam_id, student_id) 联合唯一索引防重复答卷
  - answers(exam_record_id, question_id) 联合唯一索引防重复作答
- **软删除**：questions/papers/exams 采用 deleted_at 软删除，避免引用断裂
- **字符集**：utf8mb4 + utf8mb4_general_ci，存储引擎 InnoDB

## 第 8 页 · 核心功能实现 — 题库与组卷

**标题**：核心功能实现（一）— 题库管理与组卷

**要点内容**：
- **题库管理**：
  - 5 种题型统一存储：type 枚举（single/multiple/judge/fill/short），options 存 JSON，answer 存标准答案
  - 答案编码规范：单选/判断存选项标识（"A"/"true"），多选存逗号集合（"A,B,C"），填空以 "||" 分隔多空，简答存参考答案文本
  - 多维筛选查询：按题型/难度/知识点/关键字 + 分页，(type, difficulty, knowledge_point) 联合索引加速
  - Excel 批量导入导出：exceljs 解析校验，支持部分成功部分失败反馈
  - 删除引用校验：被试卷引用时禁止删除（错误码 2001）
- **组卷功能**：
  - 手动组卷：教师逐题选择，设定分值与排序，upsert 语义支持分值更新
  - 随机组卷算法（核心）：
    1. 遍历组卷规则（题型/知识点/难度/数量/分值）
    2. 按条件筛选候选题目，校验题库是否充足
    3. Math.random() 随机排序后截取所需数量
    4. 累加总分，写入 paper_questions 关联
    5. 全程数据库事务保证原子性，失败回滚

**配图建议**：左侧题库管理界面截图，右侧随机组卷算法流程图（5 步）

**演讲备注**：随机组卷算法是技术亮点之一，重点讲事务保证原子性，约 1.5 分钟

## 第 9 页 · 核心功能实现 — 在线答题

**标题**：核心功能实现（二）— 在线答题与防作弊

**要点内容**：
- **答案暂存与断网续答**（技术亮点）：
  - examStore（Zustand）setAnswer 时同步写入 localStorage
  - initExam 时从 localStorage 恢复暂存答案，实现断网续答（NFR-13）
  - 定时器每 30 秒批量同步至服务端 saveAnswer 接口
  - 作答时节流函数（2 秒间隔）即时同步，网络失败静默重试
- **防作弊机制**（技术亮点）：
  - 切屏检测：监听 document visibilitychange 事件，记录切屏次数
  - 超阈值处理：超过 MAX_SWITCH_COUNT 弹窗警告并自动交卷
  - 禁止复制粘贴：拦截 copy/paste/cut/contextmenu 事件
  - 离开提示：beforeunload 事件离开前提示
- **倒计时与自动交卷**：
  - setInterval 每秒 tick 递减剩余秒数
  - 剩余 5 分钟 ExamTimer 切换警告样式（黄色）
  - 剩余 1 分钟切换危险样式（红色）
  - 时间为 0 自动调用交卷接口（NFR-14）
- **进入考试多重校验**：考试状态 + 时间窗口 + 学生归属班级 + 未已交卷，任一失败返回业务错误码

**演讲备注**：防作弊与断网续答是两大技术亮点，重点讲实现原理，约 1.5 分钟

## 第 10 页 · 核心功能实现 — 阅卷与成绩

**标题**：核心功能实现（三）— 阅卷与成绩统计

**要点内容**：
- **客观题自动阅卷**（交卷触发）：
  - 4 种客观题型：single/multiple/judge/fill，由系统自动评分
  - compareAnswer 按题型不同策略：
    - 单选/判断：完全匹配
    - 多选：集合相等比较（忽略选项顺序）
    - 填空：多空匹配（"||" 分隔，去空格）
  - 事务中逐条更新 answers 表 score/is_correct/graded_by(NULL)/graded_at
  - 全对得满分，错误得 0 分
- **主观题手动阅卷**：
  - short 简答题由教师逐题评分 + 填写评语
  - 自动生成阅卷任务（grade_tasks），教师进入阅卷中心处理
  - 复核改分保留 graded_by/graded_at 修改记录
- **成绩统计与可视化**：
  - 5 项分析指标：最高分、最低分、平均分、及格率、标准差
  - 5 分数段分布：0-59 / 60-69 / 70-79 / 80-89 / 90-100
  - 前端 ECharts 渲染分布柱状图与饼图
  - Ant Design Statistic 组件展示指标卡片
  - 成绩单 Excel 导出（exceljs），错题统计支持学生复习

**配图建议**：左侧阅卷流程图（交卷→自动阅卷→主观题任务→手动阅卷→汇总），右侧成绩分布柱状图截图
